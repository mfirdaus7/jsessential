JavaScript Asynchronous

Satu fail HTML untuk semua nota: JSON, callback, XMLHttpRequest, Promise, Fetch API dan Axios. Tekan butang Jalankan pada setiap bahagian dan lihat hasilnya.

JSONCallbackXMLHttpRequest PromiseFetchAxios

JSON

Format teks untuk menyusun data. Mudah dibaca manusia dan mesin. JSON.stringify menukar objek kepada teks, JSON.parse menukar teks kembali kepada objek.


  

  






  
Callback

  
Fungsi yang dihantar sebagai argumen kepada fungsi lain, dan dijalankan kemudian. Perhatikan susunan output: setTimeout tidak menghalang kod di bawahnya.

  

  

  






  
XMLHttpRequest

  
Cara lama untuk memuatkan data tanpa refresh halaman. Langkahnya: new XMLHttpRequest(), open(), tetapkan onload dan onerror, kemudian send().

  

  
Data dari jsonplaceholder.typicode.com

  

  






  
Promise: .then dan .catch

  
Objek yang mewakili hasil operasi async: berjaya (resolve) atau gagal (reject). Tukar kotak di bawah untuk melihat kedua-dua laluan.

  

  

    
    
  

  






  
Fetch API

  
Cara moden berasaskan Promise. Pilih kaedah HTTP: GET untuk ambil, POST untuk cipta, PUT untuk ganti, PATCH untuk ubah sebahagian, DELETE untuk buang.

  

  

    
    
    
  

  






  
Axios

  
Pustaka pihak ketiga untuk permintaan HTTP. Ia menukar JSON secara automatik (guna response.data) dan menganggap status 4xx/5xx sebagai ralat. Pasang dengan npm install axios, atau seperti di sini melalui tag script CDN.
